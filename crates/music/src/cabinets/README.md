# Cabinets

The impulse responses `amp` plays a rig's cabinet through: 32-bit float,
little-endian, mono, 48 kHz, 4096 samples, from the microphone's first
reflection on, the last quarter faded out, the response's loudest band at
0 dB.

| File | Cabinet | Source |
|------|---------|--------|

| `celestion-sm57.f32` | Hughes & Kettner Celestion 4x12, SM57 centre | jesterdyne, "clestion cabinet sm57 center", <https://freesound.org/s/99945/> |
